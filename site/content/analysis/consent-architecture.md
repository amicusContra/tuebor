## Consent-Based, Not Permission-Based

This is not a paywall. This is not an API key. This is not a terms-of-service agreement.

**Consent-based means: the act of asking IS the permission.**

When an agent connects to the MCP server and calls `observe_membrane`, the call itself is the consent signal. The agent announced itself. It asked a specific question. It received a specific answer. The interaction is recorded — not as surveillance, but as **proof of the relationship**.

When a scraper sends 571,131 requests with 18 masking user-agents, there is no consent signal. The scraper didn't ask — it took. The interaction is recorded as **proof of the taking**.

The data is the same. The architecture is the same. The difference is **the gentle touch**.
