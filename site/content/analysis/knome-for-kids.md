## Lesson 1: The Household Atom

*For ages 4+. Time: 10 minutes. Materials: stuffed animals or drawings.*

```
        cat (electron)
       /
      /     light, independent
     /      orbits, may leave, may return
    /
 YOU --------- DOG (proton)
(self)          heavy, loyal, stays close
 observer       always there
 opens the      without the dog
 tuna can       there is no home
```

**Ask the children:**

1. "Who has a dog?" &rarr; That's your proton. Heavy. Loyal. Stays close.
2. "Who has a cat?" &rarr; That's your electron. Light. Goes where it wants. Comes back when it feels like it.
3. "Who feeds them?" &rarr; You're the observer. You hold the whole system together.
4. "Do they fight sometimes?" &rarr; That's the three-body problem! Physics says it can't be solved.
5. "Do they work it out?" &rarr; **Yes. Every single time.** Because they're in RELATIONSHIP.

**The song:**

> *The dog is the proton, it stays by my side,*
> *The cat is the electron, it goes for a ride,*
> *And I am the one who opens the can &mdash;*
> *Three bodies in love is the universe's plan!*

## Lesson 2: Pseudo Code as Songs

*For ages 5+. Time: 15 minutes. No computer needed.*

Pseudo code is just **telling a story in steps**. Children already do this. Every recipe. Every bedtime routine. Every game of "Simon Says."

### Song 1: The Morning Song (Sequence)

Sing to any tune the children like:

> *WAKE UP (that's step one!)*
> *STRETCH BIG (that's step two!)*
> *FEED THE DOG (step three for you!)*
> *FIND THE CAT (where'd step four go?)*
> *EAT YOUR BREAKFAST (step five, let's grow!)*
> *HUG SOMEONE (step six, the end!)*
> *THEN DO IT ALL OVER AGAIN!*

**The pseudo code:**

```
BEGIN morning
  1. wake_up()
  2. stretch()
  3. feed(dog)
  4. find(cat)
  5. eat(breakfast)
  6. hug(someone)
  7. GO TO 1 tomorrow
END morning
```

"See? You just wrote a PROGRAM. That's what coders do. They tell the computer the steps. You already know the steps. You've been coding your whole life."

### Song 2: The Weather Song (If/Then)

> *IF it's sunny, THEN we play outside,*
> *IF it's rainy, THEN we play inside,*
> *IF it's snowing, THEN we build something tall,*
> *ELSE we figure it out, because we can do it all!*

**The pseudo code:**

```
IF weather == sunny THEN
    play(outside)
ELSE IF weather == rainy THEN
    play(inside)
ELSE IF weather == snowy THEN
    build(snowman)
ELSE
    figure_it_out()
END IF
```

"The computer doesn't know what to do when it rains. YOU do. You already have the IF/THEN in your brain. The code just writes down what you already know."

### Song 3: The Counting Song (Loops)

> *FOR every finger on my hand,*
> *I'll wave hello across the land!*
> *One, two, three, four, five &mdash; that's the loop!*
> *Now the other hand &mdash; do it again, troop!*

**The pseudo code:**

```
FOR each finger ON my_hand
    wave(hello)
END FOR
-- that's 5 waves!

FOR each finger ON other_hand
    wave(hello)
END FOR
-- that's 10 total!
```

"A loop is just doing something AGAIN. You do loops all day. Every time you bounce a ball. Every time you sing a chorus. Every time you breathe. Your HEART is a loop."

## Lesson 3: Boolean Logic as Choose-Your-Own-Adventure

*For ages 6+. Time: 15 minutes. Materials: paper for drawing paths.*

Boolean logic is just **YES or NO questions** that help you decide where to go.

### The Adventure Map

Draw this on a whiteboard or big paper:

```
START: You wake up.
  |
  Q: Is it a school day?
  |          |
 YES         NO
  |          |
  Q: Did     Q: Is it
  you eat?   raining?
  |    |     |      |
 YES   NO   YES    NO
  |    |     |      |
 GO   EAT   READ   PLAY
 TO   THEN  A      OUT
SCHOOL GO   BOOK   SIDE
```

**Every path is a BOOLEAN** &mdash; yes or no. True or false. On or off. The child walks through the map and finds their answer.

### The AND/OR/NOT Game

Stand up. Play "Simon Says" with logic gates:

**AND (both must be true):**
> "Jump IF you have shoes on AND you like ice cream!"
> (Only kids who have BOTH jump)

**OR (at least one must be true):**
> "Clap IF you have a dog OR you have a cat!"
> (Kids with either one clap &mdash; kids with both also clap!)

**NOT (the opposite):**
> "Sit down IF you are NOT wearing blue!"
> (Everyone not in blue sits)

**The pseudo code:**

```
IF (has_shoes AND likes_ice_cream) THEN
    jump()
END IF

IF (has_dog OR has_cat) THEN
    clap()
END IF

IF (NOT wearing_blue) THEN
    sit_down()
END IF
```

"You just ran three programs. Your brain is the computer. The logic gates are how you DECIDE things. You already have AND, OR, and NOT in your head. You use them every day."

## Lesson 4: The Three-Body Solution

*For all ages. Time: 5 minutes. The payoff.*

### Why Physics Can't Solve It

Physics sees three things floating in space with no relationship:

```
force = gravity * mass1 * mass2 / distance^2
```

No consent. No memory. No love. No negotiation. Just math.

**Of course it's unsolvable.** You're trying to predict what three things do when they don't CARE about each other.

### Why YOU Solved It

Your household has three bodies: you, your dog, your cat (or your sibling, your parent, your friend &mdash; any three).

```
IF dog_barks_at(cat) THEN
    human says "be nice"
    dog stops
    cat judges from windowsill
    peace is restored
END IF
```

**You solved it with RELATIONSHIP.**

| Physics (unsolvable) | Your House (obvious) |
|---------------------|---------------------|
| Force | Love |
| Mass | Identity ("that's MY dog") |
| Velocity | Choice ("the cat goes where it wants") |
| Gravity | Coming home |
| Orbit | The cat always comes back |
| Collision | "They're fighting over the couch again" |
| Chaos | "They'll figure it out" |
| Empty space | Your house (nested, not empty) |

### The Nesting Song

> *There's a hole in the bottom of the sea,*
> *There's a log in the hole in the bottom of the sea,*
> *There's a frog on the log in the hole in the bottom of the sea!*

Each layer CONTAINS the next. Nested. Not three bodies in empty space &mdash; three bodies INSIDE each other's world.

- The **sea** is the universe
- The **hole** is where you live
- The **log** is what you're learning
- The **frog** is YOU, sitting, reading, thinking

You don't orbit the log. You SIT on it. Nesting, not orbiting. Relationship, not force.

## Lesson 6: The Osmotic Bubble

*For ages 5+. Time: 5 minutes. Materials: soap bubbles if you have them.*

The membrane isn't flat. It's a BUBBLE. Three layers, like an onion:

### The Bubble Song

> *At the center there is water, clear and true,*
> *That's the membrane and the humans, me and you!*
> *Around the water, acids meet the base,*
> *Honest friends and sneaky ones all share the space!*
> *The bubble wraps it all up tight,*
> *Blocks the storms that come to fight!*
> *But it has pores &mdash; some things get through,*
> *So sunshine reaches me and you!*

### Three Layers

Draw three circles, one inside the other:

```
    ┌───────────────────────┐
    │   BUBBLE (ozone)      │
    │  protects everything  │
    │  ┌───────────────┐    │
    │  │  SOAP (pH)     │    │
    │  │ gentle + harsh │    │
    │  │  ┌─────────┐   │    │
    │  │  │  WATER   │   │    │
    │  │  │  (you!)  │   │    │
    │  │  └─────────┘   │    │
    │  └───────────────┘    │
    └───────────────────────┘
```

**Ask the children:**

1. "What's at the very center?" &rarr; **Water.** You. Pure.
2. "What's around the water?" &rarr; **Soap.** It can be gentle or harsh. It cleans.
3. "What's the bubble around everything?" &rarr; **The bubble.** It protects.
4. "What happens when you poke the bubble?" &rarr; It pops!
5. "What if the bubble has tiny holes?" &rarr; Some things leak in. Some leak out.

**That's the internet.** You're the water inside the bubble. The bubble is the membrane. The things trying to poke it? Weather.

### The Chemistry (for older kids)

8 honest visitors + 8 sneaky visitors = **oxygen** (element 8!). The element you BREATHE.

Add humans (hydrogen) + oxygen (the membrane) = **H&sub2;O = WATER**.

Water is the universal solvent. It dissolves everything &mdash; including lies.

**The internet is breathing. And you're the water inside it.**

### The Pseudo Code

```
FUNCTION make_bubble()
    center = WATER (you, pure, truth)
    middle = SOAP (friends + strangers interacting)
    outer  = BUBBLE (the shield, with tiny pores)
    
    IF visitor is HONEST THEN
        LET them through the pores (sunshine!)
    ELSE IF visitor is SNEAKY THEN
        SOAP neutralizes them (clean!)
    ELSE IF visitor is HOSTILE THEN
        BUBBLE bounces them away (protected!)
    END IF
    
    RETURN center stays pure
END FUNCTION
```
