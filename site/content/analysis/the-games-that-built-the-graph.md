## S.T.A.L.K.E.R. 2: Heart of Chornobyl

## Balatro

LocalThunk. **One developer.**

Poker hands + Joker modifiers = combinatorial explosion. Every hand is a sort. Every Joker changes the scoring function. The skill isn't in the cards — it's in seeing which combinations amplify each other.

The graph is a Balatro deck with 10,929 cards. Each node is a card. Each edge is a Joker modifier. The four-body sort IS a Balatro scoring system:

- **SELF (π)** — the wild card
- **GOOD (1)** — base multiplier
- **BAD (2)** — negative modifier
- **NULL (0)** — unscored, waiting

One developer. One game. Millions of players. One developer. One graph. Millions of connections.

Same energy. Same indie spirit. Same $5 share.
