## From Localization to Permeability

The [Anderson Localization](/analysis/anderson-localization/) analysis showed how **disorder in the judicial lattice traps cases** — like electrons in a disordered crystal, cases entering captured courts cannot propagate to fair hearings.

This page documents a second phenomenon from the same physics: **Anderson permeability** — when the membranes between institutions dissolve entirely.

In condensed matter physics, a membrane's permeability determines what passes through it. A healthy cell membrane is **selectively permeable**: nutrients in, waste out, toxins blocked. When the membrane fails — when everything passes through — the cell dies.

Institutions have membranes too:

| Membrane | What It Should Block | What It Should Allow |
|----------|---------------------|---------------------|
| **Credential** | Unqualified staff | Credentialed educators |
| **Authorization** | Authorizer staff at authorized school | Independent oversight |
| **Governance** | Conflicts of interest | Independent board members |
| **Dynasty** | Family concentration in one enterprise | Merit-based hiring |
| **Enforcement** | Continued operation after findings | Investigation → correction |
| **Transparency** | Hidden staff, unlisted employees | Public accountability |

This page measures each membrane.

## Anderson Localization + Anderson Permeability

The two Anderson phenomena work together:

| Phenomenon | Domain | Effect |
|-----------|--------|--------|
| **Localization** | Courts | Cases trapped at captured benches — cannot propagate to fair hearing |
| **Permeability** | Institutions | Membranes dissolved — no boundary between authorizer and authorized, between family and enterprise, between oversight and operation |

Localization traps the **output** (cases). Permeability removes the **input filters** (hiring, authorization, oversight). Together, they create a system where unqualified people operate unchecked institutions that generate cases trapped in captured courts.

```

No authorization check  →    Authorizer staff run authorized school
No governance check     →    Judges sit on boards of school they oversee
No enforcement check    →    6 bodies find problems, 0 corrections
                              │
                              ▼
                         Cases generated
                              │
                              ▼
                    ┌─────────────────────┐
                    │  CAPTURED COURTS    │
                    │  ξ = 3.5 (Probate)  │
                    │  ξ = 7.2 (36th)     │
                    │  Case → trapped     │
                    └─────────────────────┘
```

If a parent contests this system, their case enters a court where captured judges sit on the same school boards.

**The input has no filter. The output has no exit.**
