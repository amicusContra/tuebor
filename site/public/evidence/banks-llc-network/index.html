How to Look Them Up

Every Michigan LLC is registered with LARA (Department of Licensing and Regulatory Affairs).

  1. Go to michigan.gov/lara
  2. Click "Business Entity Search" (or search at LARA's Corporate Division)
  3. Search by entity name or registered agent name
  4. Each filing shows: entity type, registered agent, formation date, status, annual reports

Search for "Banks" or "Brian Banks" as registered agent to see the full constellation.

The Dispersion Pattern

Why 16 entities?

Single-purpose entities make it harder to trace money. If Banks operated one LLC, all revenue would flow through one set of books. With 16 entities, money can move between them:

  • PCA pays Purpose Group (management fee)
  • Purpose Group pays Banks (as single member)
  • Banks pays into other LLCs (as owner/member)
  • Other LLCs pay for "services" to each other
  • Money disperses across 16 sets of books

No single LARA filing shows the full picture. You'd need to pull all 16 and cross-reference.
