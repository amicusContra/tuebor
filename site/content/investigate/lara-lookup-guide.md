## How to Look Up Any Michigan LLC

Every LLC, corporation, and nonprofit in Michigan is registered with **LARA** — the Department of Licensing and Regulatory Affairs.

The search is free. It takes 30 seconds.

---

## Step 1: Go to LARA

Visit: [michigan.gov/lara](https://www.michigan.gov/lara)

Or go directly to the business entity search:
**Corporations Division → Business Entity Search**

---

## Step 2: Search

You can search by:
- **Entity name** (e.g., "Purpose Group")
- **Entity ID number** (if you have it)
- **Registered agent name** (e.g., "Brian Banks")

**Pro tip:** Search by registered agent name to find ALL entities registered by the same person.

---

## Step 3: Read the Filing

Each result shows:
| Field | What It Tells You |
|-------|------------------|
| Entity Name | Official registered name |
| Entity Type | LLC, Corp, Nonprofit, etc. |
| Status | Active, Dissolved, etc. |
| Formation Date | When it was created |
| Registered Agent | Who receives legal documents |
| Resident Agent Address | Where they receive legal mail |
| Annual Reports | Whether they're current on filings |

---

## What to Look For

### Red Flags
- **Same registered agent** across multiple entities → shell network
- **Residential address** as registered agent address → small operation claiming large services
- **Missing annual reports** → entity may be non-compliant
- **Recent formation** before a contract award → entity created specifically for extraction
- **Multiple entities at same address** → shared infrastructure
